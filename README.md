💳 Bank Credit & Debit Analytics Dashboard

🎯 Project Overview

Analyzed 100K+ bank transaction records to understand credit and debit patterns, customer behavior, branch performance, and risk indicators.

The project demonstrates how transaction analytics can support financial monitoring, suspicious transaction identification, and data-driven banking decisions.

🛠️ Tech Stack

Microsoft Excel | MySQL | Microsoft Power BI | Tableau

🔍 Key Analysis & Business Findings

- 📅 Transaction Trends: Created Year, Month, Quarter, and Day dimensions to analyze transaction activity over time.
- 💰 Credit and Debit Analysis: Calculated total credit, debit, and net transaction amounts:
  - Total Credit: ₹127.60M
  - Total Debit: ₹127.29M
  - Net Transaction Amount: ₹318.12K
- ⚖️ Credit-to-Debit Ratio: Calculated a credit-to-debit ratio of 1.00.
- ⚠️ Risk Monitoring: Identified 10K transactions flagged for further review.
- 🏦 Branch Performance: Identified City Center Branch as the highest-performing branch, with 42.9M in reported transaction value.
- 🏛️ Bank Comparison: Compared transaction activity across Kotak, Axis, SBI, ICICI, PNB, and HDFC.
- 💳 Transaction Methods: Analyzed Bank Transfer, Credit Card, and Debit Card transactions, each accounting for approximately 33%.
- 📈 Monthly Trends: Observed relatively stable activity through November, followed by a decline in December.
- 👥 Customer Analysis: Identified top customers by balance, including Michael Smith, David Smith, and David Johnson.
- 📊 Branch Growth: Examined branch performance and identified positive growth across most branches.

- Identify suspicious transactions for further investigation.

- Understand customer transaction behavior.
- Support informed financial decision-making.
- Strengthen transaction monitoring and risk management.
